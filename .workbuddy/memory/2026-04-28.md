## 博客打不开问题修复

**问题原因：** 上次提交将 index.html 替换成 Vite 入口点时，CNAME 文件留在了项目根目录而非 public/ 目录，导致 Vite 构建后 dist/ 里没有 CNAME，GitHub Pages 自定义域名绑定丢失，前台后台都打不开。

**修复内容：**
1. 将 CNAME 复制到 public/ 目录（确保构建包含）
2. 新增 public/404.html（GitHub Pages SPA 路由重定向）
3. 在 index.html 中加入路由恢复脚本
4. 提交：`3cd0e10` - fix: add CNAME to public dir and fix SPA routing for GitHub Pages

**经验教训：** 使用 Vite 构建时，所有需要部署到根目录的静态文件（如 CNAME、robots.txt、favicon 等）必须放在 public/ 目录，根目录的文件不会被打包。
